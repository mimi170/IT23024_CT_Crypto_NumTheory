## 1. Introduction

Number Theory is an important branch of mathematics that deals with integers and their properties. It plays a significant role in modern cryptography and information security.

This project focuses on practicing fundamental concepts of Number Theory and Cryptography using Python in Google Colab. It includes mathematical algorithms and their practical implementations, such as Diffie-Hellman Key Exchange, RSA Encryption, and the basic concept of Shor's Algorithm.

Through this project, I have explored how mathematical concepts are used to establish secure communication, encrypt messages, and understand public-key cryptography.

## 2. Objectives

The main objectives of this project are:

- To understand the fundamental concepts of Number Theory.
- To explore multiplicative groups and primitive roots.
- To understand the Diffie-Hellman Key Exchange protocol.
- To learn how two parties can generate a shared secret key over an insecure communication channel.
- To understand RSA public-key encryption and decryption.
- To implement the Extended Euclidean Algorithm using Python.
- To explore the basic mathematical principles behind Shor's Algorithm.
- To improve practical programming skills by implementing mathematical algorithms in Python.

## 5. Practical Implementation

The mathematical concepts discussed in this project are implemented using Python code.

The Diffie-Hellman implementation demonstrates how Alice and Bob can independently calculate the same shared secret key without directly sharing their private keys.

The RSA implementation demonstrates the process of generating public and private keys, encrypting a plaintext message, and decrypting the ciphertext to recover the original message.

The Shor's Algorithm section demonstrates the classical mathematical approach to finding factors of a composite number using period finding.
